# GoalBet — مشروع Android أولي
هذه حزمة مصدر Android Studio بواجهة داكنة وخضراء. ليست APK مبنيًا بعد.

## البناء
1. فك ضغط الحزمة.
2. افتح مجلد المشروع في Android Studio.
3. استخدم JDK 17 وانتظر مزامنة Gradle.
4. اختر Build > Build APK(s).

## الحالة
- الواجهة والتنقلات تجريبية.
- المباراة والاحتمالات المعروضة أمثلة وليست بيانات مباشرة.
- لا توجد إيداعات أو سحوبات أو رهانات بأموال حقيقية.
- يلزم تكامل مزود بيانات رياضية وألعاب مرخصة ومحفظة آمنة والتحقق من التراخيص قبل التشغيل الحقيقي.
- لا توجد مفاتيح API أو أسرار دفع ضمن المشروع.

## البناء السحابي من الهاتف عبر GitHub Actions
أضف ملفات هذا المشروع إلى مستودع GitHub جديد. عند رفع الملفات إلى الفرع `main` أو `master` سيبدأ سير بناء APK تلقائيًا، ويمكن أيضًا تشغيله يدويًا من تبويب Actions عبر `Build GoalBet APK`.
عند نجاح البناء، افتح تشغيل البناء ثم قسم Artifacts ونزّل `GoalBet-debug-apk`. هذا APK تجريبي للتثبيت والاختبار فقط.

## إذا كنت تعمل بالهاتف فقط
للبناء السحابي:
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف `GoalBet_Android_Project.zip` إلى جذر المستودع.
3. أنشئ ملفًا جديدًا داخل المستودع بالمسار `.github/workflows/android-build.yml`، وانسخ محتوى ملف سير البناء الموجود في الحزمة إلى هذا الملف.
4. افتح تبويب Actions وشغّل `Build GoalBet APK`، أو انتظر تشغيله تلقائيًا بعد الرفع.
5. افتح عملية البناء الناجحة ونزّل ملف `GoalBet-debug-apk` من Artifacts.

ملاحظة: يجب رفع ملف ZIP إلى المستودع نفسه باسم `GoalBet_Android_Project.zip` حتى يتمكن سير البناء من استخراجه.
